# GENESIS — архитектура

Принцип: **не программировать цивилизацию, а задать законы мира, из которых она может (или не может) возникнуть.**
Код описывает физику, биологию и механизмы обучения. Ни одно событие истории — первый инструмент,
первое слово, первое поселение, первая война — не прописано. Всё это *обнаруживается* аналитикой
в тот момент, когда впервые происходит.

## 1. Девять движков

## 2. Время

1 тик = 1 виртуальный час. Сутки = 24 тика, год = 60 суток (короткая орбита) = 1440 тиков, лунный месяц = 20 суток.
Все законы записаны «на тик», поэтому масштаб времени влияет только на то, *сколько тиков выполняется в реальную секунду*:

| Масштаб | Тиков/с | Комментарий |
|---|---|---|
| 1 с = 1 минута | 1/60 | часы интерполируют минуты между тиками |
| 1 с = 1 час | 1 | |
| 1 с = 1 день | 24 | |
| 1 с = 1 неделя | 168 | |
| 1 с = 1 год | 1440 | если машина не успевает, раннер честно показывает фактическую скорость |

История одинакова при любом масштабе (проверено тестом детерминизма).

## 3. Порядок шага (причинная цепочка)

```
clock.advance
scheduler: бури, затмения, похолодания (event-driven, очередь с приоритетом)
world.update: ветер→облака→дождь→влажность→свет→температура→растения (LOD)→разложение→микробы→пожары→износ построек
perceive          (только видимое и локальное)
deliberate        (каждые 12 тиков, только для самых крупных мозгов)
choose            (нейросеть + привычки + эмоции + личность + гомеостаз + инерция)
move / eat / drink / attack / experiment / work / eat_stores
social.interact   (забота, обмен, обучение, язык, ритуалы, торговля, санкции)
metabolize        (энергия, рост, вода, температура, огонь, бури, инфекции, лечение, старение)
feed_on_kills → learn_habits → psyche.update → reproduce → bury
периодически: группы/поселения/полития/конфликты, виды, статистика, снапшот
```

## 4. Экономия ресурсов

* **LOD по чанкам 16×16.** Чанки, где (или рядом с которыми) есть организмы, интегрируются каждый тик.
  Пустые чанки догоняются раз в 12 тиков **аналитическим решением логистического уравнения**
  `B(t) = K / (1 + ((K−B₀)/B₀)·e^{−rt})`. Тест: расхождение с полной детализацией < 6 %.
  Наблюдение *не* влияет на LOD — детализация определяется только причинной необходимостью.
* **Event-driven:** редкие процессы (бури, похолодания, затмения) — пуассоновские события в куче, а не опрос каждый тик.
* **Lazy evaluation:** микромир разворачивается в отдельных микробов только при взгляде в микроскоп; при повторном
  взгляде детализация догоняет агрегат (или пересэмплируется, если прошло много времени).
* **Пространственное разбиение:** равномерная сетка-хеш, полностью векторизованный поиск соседей (`physics/spatial.py`).
* **Struct-of-arrays на NumPy:** вся популяция — массивы; Python-циклы только там, где событий мало
  (разговоры, эксперименты, строительство), и с жёстким лимитом пар за тик.
* **Математические приближения:** логистический рост, SIR-подобная агрегированная эпидемиология, Клейбер (метаболизм ∝ масса^0.75), Гомперц.

Производительность (1 ядро): ~9 мс/тик при 350 организмах, < 250 мс/тик при 1500 (тест).

## 5. Ограниченное познание

`perception.py` — единственная точка, через которую организм получает данные. Она читает:
цвет/категорию растения и **видимую** часть биомассы, воду, огонь, постройки, размер и окраску соседей,
собственные ощущения (голод, жажда, боль, холод). Она **не** читает: токсичность, «запертую» энергию орехов
и клубней, патогены, вирулентность штаммов, руды, питательные вещества почвы, рацион других существ, будущее.

Тест `test_perception_ignores_hidden_reality` меняет все скрытые поля и проверяет, что восприятие бит-в-бит
не изменилось. Тест `test_hidden_microbes_still_cause_disease` проверяет, что скрытое продолжает действовать.

Уровни реальности: `macro` (известен сразу), `subterranean` (открывается копанием и находкой руды),
`microscopic` (открывается изобретением микроскопа: стекло + металл + «смотреть сквозь» на мелкое),
`celestial` (телескоп ночью). Открытие меняет поведение: знание о микробах снижает риск инфекции (гигиена),
знание неба повышает урожайность (календарь) и превращает затмения из «необъяснимого» в «естественное».

## 6. Знания добываются экспериментом

`laws.RECIPES` — это физика материалов (что произойдёт, если ударить камнем по ореху, нагреть глину на огне…).
Организм, выбравший действие `experiment`, берёт случайный глагол и случайное подмножество реально присутствующих
предметов. Мир решает, случилось ли что-то. Вероятность зависит от сложности, мозга, любопытства, возраста.
Таблицу рецептов организм никогда не читает. Навык затем распространяется подражанием/обучением,
а в поселении с письменностью — сохраняется в «библиотеке» и переживает своих носителей.

## 7. Память и обучение

* **STM:** 8 последних событий (векторизованно).
* **LTM:** консолидация событий с высокой значимостью × эмоциональным возбуждением; ёмкость 6 + 44·мозг;
  забывается наименее яркое (экспоненциальное затухание).
* **Семантическая память:** выученная ценность каждого вида растений (условно-рефлекторное отвращение к вкусу),
  выученный страх по внешности хищников, места еды/опасности/воды, навыки.
* **Привычки:** оперантное обусловливание (сдвиг склонности к действию на величину «награда − средняя награда»).
* **Эффект Болдуина возможен:** врождённые предпочтения еды наследуются и отбираются, выученные — нет.

## 8. Нравственный модуль

Семь норм (справедливость, милосердие, терпение, ответственность, правдивость, прощение, благодарность)
— **культурные**, не генетические. По умолчанию `none`: нормы дрейфуют только из опыта
(получил помощь → благодарность; подвергся нападению → меньше прощения). Исследователь может включить
«воспитательный идеал» (`quran_inspired`, `utilitarian`, `kin_loyalty`, `egoist`) с силой `moral_education`.
Каждая норма меняет конкретное поведение (делиться с не-родственниками, оставлять семенной фонд при сборе,
не лгать о еде, прекращать вражду, отвечать благодарностью). `genesis compare` запускает одинаковые миры
с разными идеалами и сравнивает исходы. Профиль `quran_inspired` — упрощённая исследовательская абстракция
добродетелей (ʿадль, рахма, сабр, амана, сидк, ʿафв, шукр), не богословское утверждение.

## 9. Эмоции и сознание

Эмоции — функциональные переменные состояния (страх, радость, гнев, печаль, привязанность), порождаемые
оценкой событий и меняющие поведение. **Модель не утверждает наличия субъективного переживания.**

## 10. Детерминизм, сохранение, перемотка

Вся случайность — один `numpy.Generator`, состояние которого входит в снапшот. Снапшот = zlib(pickle(всё состояние)).
Перемотка: загрузка ближайшего снапшота ≤ цели, удаление «отменённого будущего» из SQLite, детерминированное
воспроизведение до цели. Тест проверяет совпадение хеша состояния.

## 11. Где уместны тяжёлые модели (LLM)

Не для решений каждого организма. Подходящие точки расширения: `brain.deliberate` (уже выборочный),
генерация текстовых биографий/хроник по событиям из SQLite для наблюдателя. В текущей версии LLM не используются.

## 12. Честные ограничения

* Мир — 2D-сетка 96×96 (настраивается), а не планета-сфера; «далёкие галактики» представлены небом (планеты, звёзды).
* Возникновение интеллекта не гарантировано и в первичном сценарии за десятки тысяч часов обычно не происходит:
  мозг дорог энергетически. Сценарий `advanced` — явный экспериментальный «старт с более поздней точки»
  (социальные всеядные с крупным мозгом, **без** навыков, слов, норм и знаний).
* Технологическое дерево ограничено набором рецептов в `laws.py` (12 аффордансов) — это пространство физических
  возможностей мира, а не сценарий; но оно конечно.
* Полития (band/tribe/chiefdom/state) — измерительная классификация по Сервису, а не моделирование институтов.
